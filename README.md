# Task Manager

A full-stack task management application built with React, Vite, FastAPI, and JWT authentication.

## 🚀 Live Demo

[Live Website](https://task-manager-frontend-sable-ten.vercel.app)

[API Documentation](https://task-manager-backend-xtui.onrender.com/docs)

## ✨ Features

- User registration and JWT authentication
- Create, update, delete, and manage tasks
- Search, filtering, and pagination
- Task status and priority tracking
- Protected routes and role-based admin access
- REST API integration
- Frontend and backend tests

## 🛠️ Tech Stack

**Frontend:** React, Vite, Axios, React Router, CSS  
**Backend:** FastAPI, Python, SQLAlchemy, SQLite, JWT  
**Testing:** Vitest, Pytest  
**Deployment:** Vercel, Render
